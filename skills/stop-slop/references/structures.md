## Binary Contrasts

These create false drama. State the point directly.

| Pattern | Problem |
|---------|---------|
| "Not because X. Because Y." / "Not because X, but because Y." | Telegraphed reversal |
| "[X] isn't the problem. [Y] is." | Formulaic reframe |
| "The answer isn't X. It's Y." | Predictable pivot |
| "It feels like X. It's actually Y." | Setup/reveal cliche |
| "The question isn't X. It's Y." | Rhetorical misdirection |
| "Not X. But Y." / "not X, it's Y" / "isn't X, it's Y" | Mechanical contrast |
| "It's not this. It's that." | Same formula, different words |
| "stops being X and starts being Y" | False transformation arc |
| "doesn't mean X, but actually Y" | Negation-then-assertion crutch |
| "is about X but not Y" | False distinction |
| "not just X but also Y" | Additive hedge |
| "No X. No Y. Just Z." | Triple-negation drumroll |
| "Y rather than X" | Same negative parallelism, reversed order (Wikipedia "Signs of AI writing", accessed 2026-09-27) |

**Instead:** State Y directly. "The problem is Y." "Y matters here." Drop the negation entirely.

Judge by **density**: contrastive construction is the single most-flagged AI pattern (LinkedIn's 2026 slop filter targets it by name), but humans have used it for decades — one instance in a piece is fine; three is the tell.

## Negative Listing

Listing what something is *not* before revealing what it *is*. A rhetorical striptease.

| Pattern | Problem |
|---------|---------|
| "Not a X... Not a Y... A Z." | Dramatic buildup through negation |
| "It wasn't X. It wasn't Y. It was Z." | Same structure, past tense |

**Instead:** State Z. The reader doesn't need the runway.

## Dramatic Fragmentation

Sentence fragments for emphasis read as manufactured profundity.

| Pattern | Problem |
|---------|---------|
| "[Noun]. That's it. That's the [thing]." | Performative simplicity |
| "X. And Y. And Z." | Staccato drama |
| "This unlocks something. [Word]." | Artificial revelation |

**Instead:** Complete sentences. Trust content over presentation.

## Rhetorical Setups

These announce insight rather than deliver it.

| Pattern | Problem |
|---------|---------|
| "What if [reframe]?" | Socratic posturing |
| "Here's what I mean:" | Redundant preview |
| "Think about it:" | Condescending prompt |
| "And that's okay." | Unnecessary permission |
| "Whether you're a X or a Y, ..." | Dual-audience opener; commits to no reader |
| "Picture this:" / "Imagine a world where..." | Fake-specific scenario with no concrete detail |

**Instead:** Make the point. Let readers draw conclusions. Pick one actual reader and write to them.

## Formulaic Constructions

| Pattern | Problem |
|---------|---------|
| "By the time X, I was Y." | Narrative template |
| "X that isn't Y" | Indirect. Say "X is broken" |

## Superficial-Analysis Tails

An `-ing` clause bolted to the end of a sentence to fake analysis. It restates the obvious or gestures at significance without adding a fact.

| Pattern | Problem |
|---------|---------|
| "..., highlighting the need for X." | Tacked-on significance |
| "..., reflecting a broader shift toward Y." | Vague trend claim, no evidence |
| "..., underscoring the importance of Z." | Restates the point as if it were new |
| "..., showcasing the power of W." | Empty flourish |

**Instead:** End on the fact. If the tail carries a real claim, make it its own sentence with evidence.

## False Ranges

"From X to Y" implies a spectrum the two items don't actually sit on.

| Pattern | Problem |
|---------|---------|
| "Everything from startups to enterprises" | Filler that means "lots of companies" |
| "From code to culture" | Two items dressed as a continuum |

**Instead:** Name the actual set, or give a number.

## Signposted Conclusions

Announcing the conclusion instead of just stating it.

| Pattern | Fix |
|---------|-----|
| "In conclusion," / "To sum up," / "Ultimately," | Cut the signpost; state the conclusion |
| "The bottom line is" / "At the end of the day" | Cut; say the bottom line |

## Concession Dismissal

A rigid formula that raises a problem only to wave it away.

| Pattern | Problem |
|---------|---------|
| "Despite its challenges, X remains..." | Acknowledges nothing real, then dismisses |
| "While not perfect, X is still..." | Same formula, hedged |
| "Challenges and Future Prospects" section: vague obstacles + vague optimism | Outline-template essay ending; says nothing |
| Both-sides balancing: equal pros/cons regardless of the evidence | Manufactured neutrality; weigh what the evidence weighs |

**Instead:** If the problem is real, engage it. If it isn't, don't raise it.

## False Agency

Giving inanimate things human verbs. Complaints don't "become" fixes. Bets don't "live or die." Decisions don't "emerge." A person does something to make those things happen. AI loves this because it avoids naming the actor.

| Pattern | Problem |
|---------|---------|
| "a complaint becomes a fix" | The complaint did nothing. Someone fixed it. |
| "a bet lives or dies in days" | Bets don't have lifespans. Someone kills the project or ships it. |
| "the decision emerges" | Decisions don't emerge. Someone decides. |
| "the culture shifts" | Cultures don't shift on their own. People change behavior. |
| "the conversation moves toward" | Conversations don't move. Someone steers. |
| "the data tells us" | Data sits there. Someone reads it and draws a conclusion. |
| "the market rewards" | Markets don't reward. Buyers pay for things. |

**Instead:** Name the human. "The team fixed it that week" beats "the complaint becomes a fix." If no specific person fits, use "you" to put the reader in the seat.

## Narrator-from-a-Distance

Floating above the scene instead of putting the reader in it.

| Pattern | Problem |
|---------|---------|
| "Nobody designed this." | Disembodied observation |
| "This happens because..." | Lecturer voice |
| "This is why..." | Same |
| "People tend to..." | Armchair sociologist |

**Instead:** Put the reader in the room. "You don't sit down one day and decide to..." beats "Nobody designed this."

## Passive Voice

Default to a subject doing something — passive voice hides the actor and drains energy. Flag, don't ban: technical/security prose legitimately uses passive when the actor is unknown or irrelevant ("the port was left open"). Rewrite the ones that hide a knowable actor.

| Pattern | Fix |
|---------|-----|
| "X was created" | Name who created it |
| "It is believed that" | Name who believes it |
| "Mistakes were made" | Name who made them |
| "The decision was reached" | Name who decided |
| "Experts agree / studies show / research suggests" | Name the expert, cite the study |

**Instead:** Find the actor. Put them at the front of the sentence. "Studies show" with no study is the same dodge as the passive — name the source or cut the claim.

## Sentence Starters to Avoid

| Pattern | Fix |
|---------|-----|
| Sentences starting with What, When, Where, Which, Who, Why, How | Restructure. Lead with the subject or the verb. |
| Paragraphs starting with "So" | Start with content |
| Sentences starting with "Look," | Remove |

Wh- openers become a crutch. "What makes this hard is..." becomes "The constraint is..." or better, name the specific constraint.

## Rhythm Patterns

| Pattern | Fix |
|---------|-----|
| List always landing on three | Flag the pattern and vary length — sometimes two, sometimes three or more; do not mechanically forbid three. |
| Questions answered immediately | Flag it — let the question breathe or cut it |
| Every paragraph ends punchily | Vary endings |
| Em-dashes | Flag each one — prefer a comma or period, restructure where it is doing a comma's job, but em dashes are not forbidden; keep one where it genuinely reads best. Banning every em-dash is itself a 2026 tell of AI-anxiety editing. |
| Staccato fragmentation | Flag a run of short punchy sentences; mix in longer ones |
| "Not always. Not perfectly." | Hedging disguised as reassurance |
| Uniform paragraph geometry | Every paragraph a 3-sentence rectangle, every sentence 15–20 words. Merge some, split some — low burstiness reads machine. |
| Elegant variation / synonym cycling | Rotating synonyms to avoid repeating a word ("the firm… the company… the organisation"). Repeating the plain word is fine. |

## Formatting-Layer Tells

Slop shows in the markup, not just the words. In rendered blog HTML these are the most visible tells of all:

| Pattern | Fix |
|---------|-----|
| Bold-inline-header bullets ("**Speed:** it's fast") repeated down a list | Write sentences, or use a real subheading |
| Emoji as section bullets (🚀 ✅ 💡) | Strip them from prose |
| "X: A Comprehensive Guide" colon-subtitle headings | Say what the piece actually argues |
| `---` thematic break before every heading | Cut; headings already separate |
| Title Case On Every Heading | Sentence case |
| Bolding **every key phrase** mid-paragraph | Bold nothing, or one thing |
| Headings that skip a level (H2 → H4) or stack several H1s | Clean hierarchy; one H1 per page (also a blog-pipeline SEO-floor item) |
| "X and Y" section titles ("Challenges and Legacy", "Awards and Recognition", "Future Outlook") | Retitle with what the section argues |
| A table where a sentence would do | Tables for real comparisons only |

## Model Artifacts in Links and Markup

Chatbot residue that survives a copy-paste. On a blog post each one is also a sign the source was never opened.

| Artifact | Fix |
|----------|-----|
| `?utm_source=chatgpt.com` (or any AI-tool tracking parameter) on a link | Strip the parameter; open the link and confirm it is the primary source |
| `oaicite`, `contentReference[…]`, `[cite: 1]`, `grok_card` fragments | Delete; re-source the claim |
| Markdown (`**bold**`, `##`) leaking into HTML or JSX | Convert to the site's markup |

Source for this section and the three rows added above it: Wikipedia, "Signs of AI writing" (https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing, accessed 2026-09-27).
