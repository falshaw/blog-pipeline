## Throat-Clearing Openers

Remove these announcement phrases. State the content directly.

- "Here's the thing:"
- "Here's what [X]"
- "Here's this [X]"
- "Here's that [X]"
- "Here's why [X]"
- "The uncomfortable truth is"
- "It turns out"
- "The real [X] is"
- "Let me be clear"
- "The truth is,"
- "I'll say it again:"
- "I'm going to be honest"
- "Can we talk about"
- "Here's what I find interesting"
- "Here's the problem though"

Any "here's what/this/that" construction is throat-clearing before the point. Cut it and state the point.

## Emphasis Crutches

These add no meaning. Delete them.

- "Let that sink in."
- "This matters because"
- "Make no mistake"
- "Here's why that matters"

Judge-first, not auto-delete: "Full stop." is native British emphatic idiom ("I'm not doing it, full stop.") — keep it when it's a deliberate voice choice in UK prose; cut it when it's decorating a claim that didn't earn the emphasis. Same for "Period." in a US voice.

## Chatbot Register

Assistant-conversation moves that leak into prose. Delete on sight — they have no written-prose use.

- "Great question" / "That's a great point"
- "You're absolutely right"
- "Happy to help" / "Certainly"
- "Let's dive in" / "Let's unpack this"
- "Honestly?" / "Here's the thing" (as opener)
- "But here's the kicker" / "That's only half the story"

## Vague Authority

Weasel attributions that simulate sourcing. Name the actual source or cut the claim.

- "experts note" / "experts agree"
- "observers say" / "analysts suggest"
- "industry reports suggest"
- "widely regarded as" / "widely considered"
- "studies show" (with no study named)

## Business Jargon

Replace with plain language.

| Avoid | Use instead |
|-------|-------------|
| Navigate (challenges) | Handle, address |
| Unpack (analysis) | Explain, examine |
| Lean into | Accept, embrace |
| Landscape (context) | Situation, field |
| Game-changer | Significant, important |
| Double down | Commit, increase |
| Deep dive | Analysis, examination |
| Take a step back | Reconsider |
| Moving forward | Next, from now |
| Circle back | Return to, revisit |
| On the same page | Aligned, agreed |

## AI Vocabulary (GPT-isms)

The single most-recognized class of AI tell. These are the words a model reaches for that a person rarely types. Swap for the plain word you'd say out loud. This list is a hard flag — but it is swap-and-judge, not blind delete: a few have a correct literal use ("foster a child," a real "ecosystem," an actual "journey"), and some ("ensure," "comprehensive," "vital") are everyday UK vocabulary that only tells when it clusters. Flag every hit and keep one only when the plain word genuinely loses meaning. **Rewrite the sentence rather than swapping in a rare synonym** — thesaurus substitution produces its own detectable weirdness.

Era note: the 2023-era set (delve, tapestry, realm, beacon) has mostly vanished from current model output — treat those as low-weight legacy checks. The 2025/26-era set reaches for: **emphasizing, enhance, highlighting, showcasing, align with, fostering, pivotal, vibrant, robust, crucial, bolstered, elevate, resonate, at the forefront, treasure trove, ever-evolving / rapidly evolving / fast-paced**. Weight those higher.

| Avoid (verbs) | Use instead |
|---------------|-------------|
| Delve (into) | Look at, examine, get into |
| Leverage | Use |
| Foster | Build, encourage, grow |
| Underscore / underpin | Show, support, stress |
| Streamline | Simplify, speed up |
| Empower | Let, enable, help |
| Unleash / unlock | Release, free up, allow |
| Garner | Get, earn, attract |
| Showcase | Show |
| Ensure | Make sure |
| Boast (a feature) | Have, include |

| Avoid (adjectives) | Use instead |
|--------------------|-------------|
| Robust | Solid, reliable, strong |
| Seamless | Smooth, no friction |
| Cutting-edge / state-of-the-art | New, current |
| Multifaceted / multi-pronged | Has several parts — name them |
| Pivotal | Key, central |
| Comprehensive | Full, complete, thorough |
| Vital / crucial | Important — or cut it |

| Avoid (grand nouns) | Use instead |
|---------------------|-------------|
| Tapestry / symphony / mosaic | Cut the metaphor; name the thing |
| Landscape (of an industry) | Field, market, situation |
| Realm | Area, field |
| Beacon | Cut it |
| Ecosystem | System, set of tools, the parts |
| Journey | Process — or name the steps |
| Testament (a testament to) | Shows, proves |

| Avoid (drama / intensifiers) | Use instead |
|------------------------------|-------------|
| Transformative / revolutionary / game-changing | State the specific change |
| Myriad / plethora | Many, dozens of — or a number |
| Unwavering | Steady, consistent |
| Elevate | Improve, raise — or name the change |
| Resonate (with audiences) | Land, matter to — or cut |
| At the forefront | Leading — or name the position |
| Treasure trove | Cut; say what's in it |
| Ever-evolving / rapidly evolving / fast-paced | Cut; the field's pace is rarely the point |

## Significance Inflation

The current-generation flagship tell: dressing an ordinary fact as a milestone. State the fact plainly; if it really is significant, the evidence should show it.

- "is a testament to" → shows
- "underscores the importance of" → cut; state the fact
- "marks a key turning point" → say what changed
- "leaves an indelible/lasting mark" / "enduring legacy" → cut
- "setting the stage for" → cut, or state what actually follows
- "reflects broader trends" → name the trend and the evidence, or cut
- "deeply rooted in" → from, based on

## The "serves as" dodge

Pompous stand-ins for the verb "is." They inflate a flat statement into something that sounds momentous. Use "is."

- "serves as" → is
- "stands as" → is
- "represents" (when it means "is") → is
- "marks" (when it means "is") → is
- "acts as" → is
- "functions as" / "features" / "maintains" (when they mean "is" / "has") → is, has

## Promotional Register

Travel-guide or brochure tone in prose that is meant to be neutral. Cut the adjective or replace it with the fact that would justify it.

- "vibrant" / "bustling" · "nestled" · "rich heritage" / "rich history"
- "diverse array" · "natural beauty" · "groundbreaking" · "renowned"

## Vague Connection

Indirect phrasing that avoids saying what the relationship actually is.

- "associated with" / "in association with"
- "connected to" / "in connection with"

**Instead:** name the relationship: caused, funded, runs, replaced, depends on.

## Canned Notability Emphasis

Sentences that talk about the coverage instead of the thing: "has been featured in," "received independent coverage," "widely covered by trade publications," "maintains an active social media presence." On a blog post, cite the one source that matters and say what it found.

Source for the three sections above and the added copula verbs: Wikipedia, "Signs of AI writing" (https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing, accessed 2026-09-27). The same page dates the vocabulary eras used above: 2023 "delve," "meticulous"; 2024 "align with," "enhance"; 2025 "emphasizing," "showcasing."

## Transition Filler

Connective words AI drops in to sound structured. Most can be cut; the sentence stands on its own.

- "Furthermore," / "Moreover," / "Additionally," — cut, or use "Also," sparingly
- "In conclusion," / "To sum up," / "To wrap up," — cut; just state the conclusion
- "That being said," / "With that said," — cut, or "But"
- "It is important to note that" / "It's worth mentioning" — cut
- "Needless to say" — then don't say it

## Adverbs

Flag every adverb: cut the empty ones, keep the load-bearing ones that change the meaning (e.g. precise -ly words like "quarterly"). The offenders below are almost always empty — cut them on sight; keep an adverb only when removing it loses information.

Specific offenders:

- "really"
- "just"
- "literally"
- "genuinely"
- "honestly"
- "simply"
- "actually"
- "deeply"
- "truly"
- "fundamentally"
- "inherently"
- "inevitably"
- "interestingly"
- "importantly"
- "crucially"

Also cut these filler phrases:

- "At its core"
- "In today's [X]"
- "It's worth noting"
- "At the end of the day"
- "When it comes to"
- "In a world where"
- "The reality is"

## Meta-Commentary

Remove self-referential asides. The essay should move, not announce its own structure.

- "Hint:"
- "Plot twist:" / "Spoiler:"
- "You already know this, but"
- "But that's another post"
- "X is a feature, not a bug"
- "Dressed up as"
- "The rest of this essay explains..."
- "Let me walk you through..."
- "In this section, we'll..."
- "As we'll see..."
- "I want to explore..."

## Performative Emphasis

False intimacy or manufactured sincerity:

- "creeps in"
- "I promise"
- "They exist, I promise"

## Telling Instead of Showing

Announcing difficulty or significance rather than demonstrating it:

- "This is genuinely hard"
- "This is what leadership actually looks like"
- "This is what X actually looks like"
- "actually matters"

## Vague Declaratives

Sentences that announce importance without naming the specific thing. Kill these.

- "The reasons are structural"
- "The implications are significant"
- "This is the deepest problem"
- "The stakes are high"
- "The consequences are real"

If a sentence says something is important/deep/structural without showing the specific thing, cut it or replace it with the specific thing.

### Weasel Attribution
Vague sources standing in for evidence. Name the source or cut the claim.
- "Experts agree", "Studies show", "Research suggests", "Many believe", "It is widely accepted", "Industry insiders say"

### Faux-Insight Setups
Promising a secret, then delivering an ordinary point.
- "What nobody tells you", "The part everyone misses", "Here's what most people get wrong", "The real secret is", "What they don't teach you"

### Importance Puffery
Inflating significance instead of showing the specific consequence.
- "A testament to", "Marks a pivotal moment", "A watershed moment", "Game-changer", "Paradigm shift", "Redefines the landscape", "Sets a new standard", "Underscores the importance of"

### Superficial Analysis Tails
A trailing clause that praises or interprets instead of informing.
- "…, highlighting the team's commitment to innovation", "…, underscoring its importance", "…, reflecting a broader trend", "…, showcasing its potential"

### Fake-Profound Endings
Closing lines that sound deep and say nothing. End on the last concrete point instead.
- "The future isn't coming. It's already here.", "And that changes everything.", "The question isn't if, but when.", "In the end, it's about people."

## German AI tells (Deutsch) — fork addition

Same logic for German drafts (blog posts, business mail, guides). Cut or replace with the concrete point.
- Openers: „In der heutigen schnelllebigen (digitalen) Welt“, „In diesem Artikel werden wir“, „Lassen Sie uns eintauchen“, „Stellen Sie sich vor“
- Filler: „Es ist wichtig zu beachten, dass“, „Es lässt sich festhalten“, „Darüber hinaus“ / „Des Weiteren“ am Satzanfang in Serie, „Nicht zuletzt“
- Puffery: „spielt eine entscheidende/zentrale Rolle“, „von entscheidender Bedeutung“, „ein Meilenstein“, „auf ein neues Level heben“, „Mehrwert schaffen“, „Herausforderungen meistern“
- Buzzwords: „nahtlos“, „ganzheitlich“, „maßgeschneidert“, „innovativ“, „zukunftssicher“, „ein Muss“
- Closers: „Zusammenfassend lässt sich sagen“, „Fazit:“ followed by a restatement, „Die Zukunft ist jetzt“
- Contrast formula: „Es geht nicht um X, sondern um Y“ on repeat; „nicht nur … sondern auch“ more than once per text
- Denglisch overload: English where common German exists (Disclosures → Veröffentlichungen, Failure-Modes → Fehlerbilder, Payoff → Ergebnis, Research → Forschung). Keep genuine terms of art (Prompt Injection, MCP, Zero Trust).
- Business / application mail: „Ich freue mich sehr“, „sehr gut zu meinem Profil“, „spannende Herausforderung“ — say the fact (Schwerpunkt, Verfügbarkeit, Satz) instead.
